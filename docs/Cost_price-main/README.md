## محدودیت قطعی
روی سرور اصلی فقط SELECT و CTE؛ هیچ DDL/DML، جدول موقت یا Stored Procedure. موتور مستقل روی سرور گزارش‌گیری یا Python. تست فعلی روی کپی داده واقعی SQL Server 2022 است. MAXDOP 1 برای تشخیص؛ توقف تست سنگین پس از 60 ثانیه. NOLOCK ممنوع. خروجی تشخیصی خلاصه، حداکثر 100 ردیف؛ نمونه استثنا ترجیحاً حداکثر 20 ردیف.

## دامنه
تاریخ شروع 2022-08-18؛ آخرین گردش مشاهده‌شده 2026-11-15. حد بالای کوئری‌های جاری 2026-11-25 به صورت exclusive. LedgerRef=1؛ مرکز هدف 2، مراکز 1 و 4 برای وابستگی‌ها. همه مقادیر در واحد اصلی کالا؛ مبالغ ریال. اطلاعات مالی واقعی و شناسه اسناد در مخزن عمومی ثبت نمی‌شوند.

این مستندات بازسازی یافته‌های موجود تا تاریخ فوق هستند، نه DDL رسمی فروشنده و نه اثبات کامل همه حالات. وضعیت تایید، تخمین و استثنا باید جدا بماند.
